# UI 规范

本文规定 YXRL 的视觉与组件标准，是原型样式 [styles.css](prototype/styles.css) 和后续 WPF 资源字典的共同依据。操作行为见 [交互规范](interaction-spec.md)，界面截图与流程见 [界面与交互](ui-interactions.md)。数值以 DIP（与 CSS px 等价）为单位。

## 设计原则

1. **日期优先**。面板空间全部用于日期和个人安排，没有广告、会员或推荐入口。
2. **紧凑而可读**。信息密度参照 Windows 11 系统日历，但正文不小于 11 DIP，操作文字不小于 12 DIP。
3. **状态不只靠颜色**。选中、今天、休／班、开关开启都同时使用形状、文字或位置区分。
4. **跟随系统**。浅色、深色和高对比度均使用同一组语义令牌，不在组件里写死颜色。
5. **一处定义**。同一业务含义只有一种视觉。例如日程的分类色块在月历、详情和设置预览中一致。

### 日程分类色

分类决定日程色块的左边和底色。浅色标记以 `--cat-bg` 为底、`--cat-ink` 为字；实色填充以 `--cat-color` 为底、白字。

| 分类 | `--cat-color` | 浅色底 / 字 | 深色底 / 字 |
| --- | --- | --- | --- |
| 工作 | `#27669f` | `#e2effd` / `#164a75` | `#254157` / `#c9e6ff` |
| 个人 | `#26785f` | `#e1f3ec` / `#17573f` | `#253f38` / `#b4e8d2` |
| 默认 | `#785695` | `#eee8fa` / `#593e71` | `#463850` / `#ead7fa` |

### 对比度要求

正文和操作文字对比度不低于 4.5:1。按当前令牌实测：

| 组合 | 浅色 | 深色 |
| --- | --- | --- |
| 正文 / 面板 | 14.3 | 12.8 |
| 次要文字 / 面板 | 5.9 | 7.8 |
| 周号、`--faint` / 面板 | 5.4 | 6.3 |
| 强调色 / 面板 | 6.7 | 8.1 |
| 强调色上的文字 | 6.9 | 8.2 |
| 周末 / 面板 | 6.1 | 8.2 |

新增或调整令牌后重新计算本表。邻月日期以 75% 不透明度弱化，属于辅助信息，不作为唯一读取来源。

## 字体与字号

字体栈：`Segoe UI Variable Text`、`Segoe UI`、`Microsoft YaHei UI`、`Microsoft YaHei`。时间、日期数字、周号一律使用等宽表格数字。

| 层级 | 字号 | 字重 | 用法 |
| --- | --- | --- | --- |
| 主时钟 | 46，秒数 26 | 620 | 月历顶部，字距 −2，秒数用次要色 |
| 设置页标题 | 23 | 650 | 与左侧导航名称一致 |
| 月份标题 | 20（年、月单位 13） | 650 | 月历工具行 |
| 面板标题 | 17 | 630 | 详情、编辑、对话框标题 |
| 日期数字 | 15 | 600 | 日期格主行 |
| 小节标题 | 14 | 650 | 「今日安排」「日程与待办」 |
| 正文、设置行 | 13 | 400 | 设置项、列表、按钮 |
| 辅助文字 | 12 | 400 | 标签、链接、提示、顶部日期行（13） |
| 下限 | 11 | 400 | 日期格副标题、周号、标签；「休／班」角标 10 |

任务栏时钟是系统区域，字号随可用高度自适应，最大约 12.25，不套用上表。

## 间距、圆角与层级

- **基本间距**为 8，常用倍数 4、8、12、16、20。面板水平内边距约 18–20。
- **圆角**：窗口与面板 12，卡片与分组 7，日期格 8，按钮、输入框、导航项 6，标签与角标 3–5。
- **阴影**：窗口使用 `0 12px 40px` 加 `0 2px 8px` 双层浅阴影，深色加深；不叠加彩色光晕。
- **分隔**：区块之间用 1 的 `--line`，不用额外留白代替。
- **层级**：桌面 → 任务栏 → 月历、设置窗口、编辑面板 → 模态对话框（带遮罩）→ 提示条。

## 窗口与布局尺寸

| 对象 | 尺寸与位置 |
| --- | --- |
| 月历 / 日详情 / 事项编辑 | 宽 420，贴近任务栏并留出间隔；高度超出工作区时内部滚动 |
| 设置窗口 | 宽最大 810，居中；标题栏高 39；左侧导航 136，内容区可滚动 |
| 对话框 | 宽最大 365，居中，背景遮罩 |
| 任务栏时钟 | 默认宽 161，窄 85；高度跟随任务栏 |
| 月历网格 | 周号列 19 加七列等宽；日期格最小高 45（视口高度 ≥840 时 49），行间距 2 |

月历与编辑面板同宽，使两者来回切换时窗口边界保持不动。设置窗口较长时，在 1130 × 780 视口内仍须完整显示标题栏和关闭按钮。

## 组件规范

### 日期格

结构为日期数字加副标题，右上可有「休」或「班」角标。副标题优先级：节日 → 节气 → 农历初一显示月名 → 农历日。节日和节气用强调色。

| 状态 | 表现 |
| --- | --- |
| 普通 | 透明底，文字 `--text`；周末用 `--rest` |
| 悬停 | `--subtle` 底 |
| 今天 | `--accent` 实心底，文字 `--on-accent` |
| 选中 | 1 `--accent` 描边加 `--accent-fill` 底 |
| 今天且选中 | 实心底加 2 的面板色内框和描边 |
| 邻月 | 75% 不透明度；仅在「显示非当前月日期」开启时出现 |
| 超出可翻范围 | 禁用，不响应点击 |
| 键盘焦点 | 2 的 `--ring` 焦点环，偏移 2 |

「休」使用 `--rest`，「班」使用 `--positive`，角标均带底色，可叠在实心今天格上。

### 日程行与待办行

- 行高 36，行内间距 9。待办在左侧放 15 的复选框，日程为整行色块。
- 日程色块：左边 3 的分类色边，圆角 3/6，内边距 6/10/6/9，右侧用小号文字显示「重复 · 时间」，无时间显示「全天」。
- 待办完成：复选框勾选，文字加删除线并改用 `--muted`。
- 月历下方最多显示前两条，其余通过「查看详情」进入。

### 按钮

| 类型 | 样式 | 用于 |
| --- | --- | --- |
| 主按钮 | `--accent` 底，最小高 32，13px / 570 | 添加事项、保存、应用样式 |
| 次按钮 | `--paper` 底，`--panel-border` 边 | 取消、试听 |
| 文字按钮 | 强调色，12px，悬停 `--subtle` | 查看详情、回到月历、设置行内链接 |
| 危险文字按钮 | `--danger` 色，图标加「删除」 | 事项、节日删除入口 |
| 图标按钮 | 30 × 30，必须有 `aria-label` 与 `title` | 翻月、关闭、返回、设置 |

每个页面只有一个主按钮。禁用态 45% 不透明度。所有按钮悬停与边框变化用 0.12 秒过渡，减弱动效时关闭。

### 表单控件

- 输入框与下拉框最小高 33，`--paper` 底，`--panel-border` 边，圆角 6。标签放在控件上方，12px `--muted`。
- 错误文字在控件下方，`--danger` 色，12px，不影响布局时才显示。
- 双列字段用 12 间距，如「时间 / 全天」「重复 / 提醒」。
- 焦点环为 2 的 `--ring`，偏移 2，所有可聚焦元素统一。

### 开关与设置行

- 开关 36 × 20，开启为 `--accent` 底且圆点在右，关闭为空底、`--faint` 描边且圆点在左。两种状态靠位置和颜色同时区分。
- 设置行最小高 36，文字作为标签占满整行，点击文字等同点击开关；悬停整行有 `--subtle` 底。
- 行内次要入口（如「模拟登录」「声音设置」）放在开关左侧，12px 链接。

### 设置窗口

- 标题栏只写「设置」，页面标题由内容区 `h2` 承担，并与左侧导航名称一致。
- 导航项高 34，选中项有 3 × 16 的强调竖条和 `--accent-fill` 底。
- 「城市与天气」打开对话框而非页面，位于导航底部，用分隔线隔开，带 `aria-haspopup="dialog"`。
- 内容区按 `option-group` 分组，每组有 12px 标题，组内用设置行。

### 卡片与分段控件

- 时钟样式卡片：九宫格，选中态为 `--accent` 描边、`--accent-fill` 底，右上角显示 14 的对勾圆标。
- 节日类型使用分段控件：`--subtle` 底，选中项为 `--accent-fill` 加粗。
- 日程配色预览卡与真实日程行使用同一套分类色。

### 时钟预览

时钟样式页的「任务栏预览」模拟系统时钟：13px、行高 17、右对齐、半透明条底色，上下两行与任务栏实际排布一致。

### 提示条与对话框

- 提示条位于任务栏上方居中，`--accent` 底，停留 2.2 秒，使用 `role="status"` 且 `aria-live="polite"`。
- 对话框使用原生 `dialog`，标题行含关闭按钮；破坏性确认的默认焦点在「取消」。

## 任务栏时钟

宽度足够时显示完整两行。不足时时间固定，其余字段拆成多页，每 4 秒翻一页。相邻系统按钮的边界不得遮挡。锁定时仅显示短时间和日期。离线缓存时，天气相关预设的第二行附「缓存」。

## 无障碍

- 所有交互元素可用键盘到达，焦点环可见。图标按钮、开关和日期格有可读名称。日期格名称包含完整日期、星期、副标题和休／班。
- 月历日期格仅当前日期可 Tab（roving tabindex），方向键移动。
- 开关使用 `role="switch"` 和 `aria-checked`；时钟按钮的名称含当前时间文本。
- 支持减弱动效：关闭过渡和平滑滚动。
- 高对比度模式下，今天、选中日期、选中卡片、导航当前项和开启的开关都加 `Highlight` 轮廓，背景山形装饰隐藏。

## 响应式（原型预览）

- ≤1000：原型导航栏收窄，设置导航缩为 113。
- ≤760：隐藏原型导航，改为顶部「演示环境」按钮和界面下拉；任务栏左对齐。
- ≤520：设置导航改为顶部横向标签、隐藏图标；时钟字号降至 40。

正式桌面窗口固定宽 420，不使用这些断点；它们仅保证评审原型在窄窗口可用。

## 与桌面版的对应

当前 WPF 的 [Theme.cs](../src/Yxrl/Views/Theme.cs) 仍使用另一组颜色（浅色强调色 `#195CCA`，深色面板 `#20252D`），与本文令牌不一致。接入面板窗口前，需决定以哪一组为准并统一。统一后，令牌名应原样映射为 WPF 资源键，在单处定义。

## 变更约定

修改令牌、字号、尺寸或组件状态时，同时更新本文、原型样式，并按 [界面与交互](ui-interactions.md#验收与重新导图) 重新导出截图。
