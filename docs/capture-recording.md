# 截图、标注与录屏

从月历底栏「截图工具」或 Ctrl+1 打开选区。截图和录屏共用选区入口，以及 YXRL 的颜色、字体、焦点与窗口样式。

## YXRL 交互

### 取色与贴图

- 截图或图片贴图中按住 `Alt` 查看中心像素。按 `Shift` 轮换 HEX、RGB、HSV、HSL，按 `C` 复制当前显示的值。坐标以 Windows 桌面的物理像素为准。截图时复制颜色会结束当前选区，贴图中复制颜色会留在贴图上。
- `Ctrl+2` 优先钉住剪贴板图片。完整 HEX、RGB、HSV 或 HSL 色值生成颜色贴图，其余纯文本生成文字贴图。色卡显示色块和各格式值，点击相应行复制。文字可拖选复制，用标题栏拖动贴图。`Ctrl+3` 恢复最近关闭的图片、文字或色卡。
- 框选前移动鼠标会提示当前窗口。在支持 UI Automation 的界面中，按住 `Ctrl` 悬停查看控件边界，点击确认控件选区。找不到控件时保留同位置的窗口选区。也可以直接拖框。

### 图片识别与导出

1. 框选图片或打开图片贴图的「识别」菜单，选择「提取文字」「文档识别」「图片转表格」或「公式识别」。三个高级识别快捷键默认使用 `Shift+E`、`Shift+Q` 和 `Shift+F`，仅在截图和图片贴图内生效。
2. 高级模型首次使用时显示用途和下载大小。点击「下载模型」后显示进度，可以取消，失败后可以重试。下载完成后识别当前图片。模型按版本保存在本机，以后断网可识别。
3. 左侧原图用于对照。文档结果可校对标题与正文，导出可编辑 Word，识别到的配图随对应段落保存。表格可逐格校对，复制为制表符分隔文本或导出 Excel，保留空格位、合并表头和文本编号。公式可编辑并复制 LaTeX。
4. 截图翻译提供 17 种目标语言和自定义输入。OCR 在本机运行。点击翻译才向配置的服务发出文字。

### 截图和标注

- 选区上方显示坐标、尺寸。下方工具栏保留常用图形、「文字」「序号」「录屏」和输出动作。空间不足时工具栏换行或移到选区上方。
- 选「序号」后显示下一号、大小、颜色和形状。轻点依次放 1、2、3。拖动新序号时从起点放置编号，向终点画箭头。点击已有序号可拖动或按 Delete 删除，双击可添加说明。撤销和重做时更新下一号。
- 点「文字」后点画布输入。Enter 换行，Ctrl+Enter 确认，Esc 放弃本次输入。点选已有文字可拖动，双击可继续编辑。字体、字号、颜色、粗体、斜体、描边和背景对新建或所选文字生效。
- Ctrl+Z 和 Ctrl+Y 操作本图的标注历史。复制、保存和钉住保留可见标注，OCR 继续遮盖马赛克区域。
- Ctrl+A 选光标所在的屏幕，Ctrl+Shift+A 选择整个虚拟桌面。
- 框选会滚动的内容，按 L 或点「长截图」。选纵向向下或横向向右，滚动原窗口时保留足够重叠。自动拼接可关闭，也可逐屏点「拼接下一屏」。完成后打开置顶贴图，可继续标注、复制或保存原尺寸 PNG。匹配不可靠时保留已拼接的部分。

### 录屏

1. 框出矩形后点「录屏」或按 G。关闭冻结层，让原窗口继续交互，并在选区外沿显示置顶录制范围框（带鼠标穿透、不抢焦点，且通过系统排除捕获机制确保不进入录制视频）。控制条显示区域尺寸、帧率、倒计时、光标、模式和声音选项。缺省 24 帧/秒，光标开启，声音由用户显式开启。
2. 点「开始录制」。准备就绪时范围框呈蓝色虚线与角标，延时倒计时期间切为橙色实线并在中央显示倒计时数字，进入正式录制后变为红色实线呼吸边框且控制条显示计时和红色录制状态。点「暂停」后计时停住、范围框转为琥珀色虚线，继续后保留同一段文件；停止、放弃或退出时自动销毁范围框。屏幕区域采用物理像素，选区至少 40 × 40。视频编码需要偶数尺寸时从右侧或底部缩减 1 像素。控制条优先放在选区外。
3. 停止后普通模式进入回放，可播放、跳转、剪头尾、按像素裁四边和调整为 0.25 至 2 倍速。快速模式在开始前选路径，停止后生成 MP4。放弃时由用户确认，临时录制素材随会话清理。
4. 录前可开「摄像头」，选择本机设备、四个角的位置和圆形或矩形。画中画写入视频。系统声音、麦克风、鼠标点击和快捷键显示均默认关闭。开启麦克风后可从设备列表选择。键盘动画采集 Ctrl、Alt、Win 快捷键和功能键，鼠标动画显示选区内的点击和滚轮。录制暂停时停止追加画面、声音和动画。
5. 「回放 → 音轨」为系统声音和麦克风分别提供 0–100% 音量和静音，可在播放时调整。「鼠标动画」和「快捷键动画」可分别关闭。MP4 保存调整后的 AAC 混音，动态图片只保存画面。导出失败时保留回放素材。
6. 录制在当前用户数据目录定期封存可读视频片段、两份音频和动画事件。重启时发现上次未清理的录屏会提示恢复，也可从月历的「截图工具 → 恢复录屏」打开。恢复从可读片段开始，尚未封存的结尾可能丢失。确认放弃会清理该次录制。

## 验收

- 在实际桌面截一张示例图，连续钉 1、2、3，写两行字，移动或修改后撤销重做。回读复制、置顶贴图和 PNG 输出。
- 对纵向和横向长截图使用已知重叠的画面，回读结果尺寸和每一行或列的像素。
- 选中包含动态内容的区域，录制、暂停、继续、停止，核对回放与文件的分辨率、时长和两个实际画面。分别验证 MP4、GIF、WebP，以及快速模式。
- 离线原型以合成画面模拟操作和回放；桌面发布包读取当前 Windows 屏幕并本机编码。
